04

你的设备，我们都想到了

具体的客户端名称和下载地址，登录用户中心后都能看到最新版本。这里先告诉你每个平台该怎么准备。

WINDOWS

Windows 电脑

下载安装包后一路“下一步”即可。首次启动时如果系统弹出防火墙提示，记得点“允许”，不然客户端连不上网。

MACOS

macOS 电脑

拖进“应用程序”文件夹就装好了。如果提示“无法打开未经验证的开发者”，到系统设置的“隐私与安全性”里点一下允许。

IOS

iPhone / iPad

iOS 端需要通过 App Store 获取对应客户端，具体名称和区服要求以用户中心的说明为准。装好后导入订阅就能用。

ANDROID

Android 手机

从用户中心下载安装包直接安装。部分国产系统会提示“未知来源”，在设置里允许一次即可，之后正常更新。

05

大家最常问的几件事

点开看看，你的问题大概率已经有人替你先问过了。

我是完全的新手，该买哪个套餐？
先问自己两个问题：有几台设备要同时用？每个月大概看多少视频？如果是一两个人、三台设备以内，基础版（¥15/月）绰绰有余。建议先月付试一个月，用得顺手再转年付，年付相当于省两个月的钱。
100GB 流量大概能用多久？
粗算一笔账：看一小时高清视频大约消耗 1–2GB，刷网页和聊天几乎不怎么费量。如果你每天看两三小时视频，100GB 差不多刚好一个月。追剧重度用户建议直接上旗舰版的 300GB，不用月底数着流量过日子。
设备数超了会怎样？
套餐里的设备数指的是“同时在线”的数量。比如基础版支持 3 台同时在线，第 4 台连上来时，最早连接的那台会被挤掉。家里设备多的话，建议直接选旗舰版（5 台）或团队版（20 台）。
客户端装好了，但连不上怎么办？
按这个顺序排查：第一，确认订阅链接已经正确导入，节点列表不是空的；第二，换一个节点试试；第三，检查系统防火墙或安全软件有没有拦截客户端；第四，确认套餐流量还没用完。四步都试过还不行，就去用户中心提交工单，旗舰版用户有 7x24 优先支持。
可以从基础版升级到旗舰版吗？
可以。在用户中心选择升级套餐即可，不需要重新注册账号，订阅链接和客户端配置都不受影响。升级后流量额度和设备数按新套餐计算。
团队版的“企业定制路由”是什么？
简单说，就是团队版可以根据你们的实际业务需求，定制特定网站或服务走特定线路的规则。比如让办公服务走稳定线路、下载走大带宽线路。具体需求可以和专属客户经理沟通，他们会帮你配置好。
